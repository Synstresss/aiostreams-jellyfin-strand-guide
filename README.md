# AIOStreams + Jellyfin + external player guide

This folder is ready for GitHub Pages.

## Publish

1. Create a public GitHub repository.
2. Upload `index.html` and the complete `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/(root)`, then save.

Do not rename or move the images unless you also update their paths in `index.html`.

## Local preview

Open `index.html` in a browser. The guide has no external dependencies.
